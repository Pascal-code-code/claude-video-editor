# Aufnahme-Regeln (dem Nutzer vor dem Dreh sagen)

- Handy **quer**, auf Stativ, auf Augenhöhe.
- Du stehst oder sitzt leicht **links** der Mitte. Rechts neben dir freie Wand: dort landen Text und Grafiken.
- Licht von vorn (Fenster oder Lampe hinter der Kamera).
- iPhone: Einstellungen → Kamera → Video aufnehmen → **HDR-Video aus**. (Mit HDR klappt es auch, dauert aber länger.)
- Ansteck-Mikro, wenn vorhanden.
- Alles in **einem Durchgang**. Versprochen? Kurz Pause, den ganzen Satz neu sagen. Claude nimmt den letzten sauberen.
- Gesten mitspielen: Hand hinhalten, zur Kamera werfen, Hände vors Gesicht, zeigen, an den Kopf fassen.
  Die Geste im Original beweist den Effekt oben.
- Datei (.mov oder .mp4) in den Ordner `input/` legen.
